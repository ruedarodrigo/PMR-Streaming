
# PMR Streaming

Peactica de un proyecto web para realizar una pagina de straming usando HTML, CSS, Bootstrap y git.

## Tecnologías usadas
- HTML
- CSS
- Bootstrap
- Bootstrap icon
- Git

## Funcionalidades
- Navbar responsive
- Página de detalle de película
- Carrusel de películas
- Página de error 404
